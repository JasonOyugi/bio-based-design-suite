Push at the end of each approved phase. Do not start a phase until Jason approves the one before it. `simplify-code` at the end of each phase; `systematic-debugging` when something breaks.

**Goal:** A static browser workspace where a user takes the mid-rise template, chooses a floor, wall, roof and frame system per element, sees data checks, and gets a schedule and BOQ with ranged, graded, landed cost, plus % validated.

**Architecture:** A static Vite + React + TypeScript single-page app with hash routing. All maths lives in a pure, fully unit-tested domain layer (`src/domain`). ## 2. Data schema (design; implemented in Phase 3)

Everything hangs off this, so it is set out in full here. Spike S3 tests its riskiest part (layers → quantities) before Phase 3 commits to it.

### 2.1 Design goals

1. **No bare evidence numbers.** Every claim is a ranged, graded, sourced `MetricValue`.
2. **Unknown ≠ placeholder.** A placeholder is a stated, flagged guess. An unknown is something nobody has told us yet. Unknowns never become numbers: they propagate as gaps, and the gaps list is generated, not hand-kept.
3. **Every number is addressable**, so the Validation Log can point at it and % validated can be computed by walking the data.
4. **Add a file, not code.** Products, routes, assemblies, building types, sources and validations are all one-file additions.
5. **Bottom-up cost drives the BOQ.** Toggling a line between imported and regional routes must change the cost, and only a bottom-up model does that. The Studio III "cost vs baseline" ratio is kept as a reference figure shown beside it, never mixed in.
6. **Honest maths.** Interval arithmetic with independent worst-case bounds; the weakest grade wins.

### 2.2 Primitives (`src/domain/`)

```ts
// grade.ts: weakest → strongest (brief §2)
export const GRADES = [
  'placeholder', 'published_spec', 'engineering_judgement', 'quote_or_QS',
  'prototype_tested', 'accredited_lab_tested', 'live_project', 'repeat_project',
] as const;
export type Grade = (typeof GRADES)[number];
export const gradeRank = (g: Grade) => GRADES.indexOf(g);
export const weakest = (gs: Grade[]): Grade => gs.reduce((a, b) => (gradeRank(b) < gradeRank(a) ? b : a));

// sourceType: the kind of source, separate from how strong the evidence is
export const SOURCE_TYPES = [
  'team_assumption', 'datasheet', 'technical_approval', 'epd', 'regulation', 'market_rate',
  'engineer_estimate', 'supplier_quote', 'qs_estimate', 'test_report', 'project_record',
] as const;

// units.ts: closed registry; compound units are "NUM" or "NUM/DEN"
// tokens: mm m m2 m3 kg t nr day week min dB % ratio kN kgCO2e + ISO currencies KES UGX TZS RWF USD EUR ZAR
// e.g. "EUR/m3", "kgCO2e/m2", "KES/EUR" (FX = quote/base), "m3/m2", "kN/m2"
export function parseUnit(u: string): { num: string; den?: string };   // throws on unknown tokens
```

```ts
// metric.ts
export const MetricValue = z.object({
  low: z.number().finite(),
  central: z.number().finite().optional(), // best estimate; when absent, maths uses the midpoint, flagged as such
  high: z.number().finite(),
  unit: UnitId,                        // validated against units.ts
  grade: GradeEnum,
  source: z.string(),                  // id in data/sources (cross-checked)
  sourceType: SourceTypeEnum,
  date: IsoDate,                       // when the value was stated or observed
  validatedBy: z.string().optional(),  // a validation entry id, never a name; names resolve only inside the Validation Log
  note: z.string().optional(),
  toConfirm: z.array(z.string()).optional(),
  singleEstimate: z.literal(true).optional(),                 // "~" values: low = high
  basis: z.enum(['first_of_kind', 'repeat', 'unknown']).optional(), // required on money units (refine below)
}).refine((v) => v.low <= v.high, 'low must be ≤ high')
  .refine((v) => v.central === undefined || (v.low <= v.central && v.central <= v.high), 'need low ≤ central ≤ high')
  .refine((v) => !v.singleEstimate || v.low === v.high, 'single estimate needs low = high')
  .refine((v) => !isMoneyUnit(v.unit) || v.basis !== undefined, 'cost values must state first_of_kind, repeat or unknown');
// Placeholders state their real sourceType (e.g. a placeholder taken from a market rate); no grade/sourceType coupling.

export const UnknownValue = z.object({
  unknown: z.literal(true),
  unit: UnitId,
  toConfirm: z.array(z.string()).min(1),   // what we need to be told
  note: z.string().optional(),
});
export const MetricOrUnknown = z.union([MetricValue, UnknownValue]);
```

**`MetricRef`** (the address of any number): `collection/id#path`. Array items with an `id` are addressed by id, so refs survive reordering: `products/busoga-kd-pine#priceExWorks`, `assemblies/f-03b#layers[topping].thickness`, `routes/jinja-nairobi#charges[haulage].value`. One generic walker (`walkMetrics(entity)`) yields `{ref, value}` for every MetricValue and UnknownValue, which feeds gaps, % validated and the ranked list. Ids can contain supplier names, so refs and ids are internal keys only: the UI, the call list and the CSV/evidence exports always print display labels (supplier alias, layer label), never raw refs or ids.

**Ranges** (`range.ts`): `{low, central, high, centralIsMidpoint}` with `add`, `sum`, `mul`, `div`, `scale` and `sub`. Bounds use interval arithmetic: `sub` is conservative (`[a.low − b.high, a.high − b.low]`). The central value applies the same operation to the centrals (sum of centrals, product of centrals), which always stays inside the bounds for the non-negative quantities used here. If a value has no stated `central`, the midpoint is used and `centralIsMidpoint` propagates, so the UI can say "central = midpoint of range". Totals show the central value prominently with the low–high range beside it. Central values also weight % validated and the call list. Low and high are plausible bounds, not a statistical interval, and the UI says so.

**routes/**
```ts
{ id, name: "EU → Mombasa → Nairobi", mode: 'imported' | 'regional',
  originCountries: ISO2[], destination: { country: ISO2, place: string }, via?: string[],
  transitTime: MetricOrUnknown /* day */,
```

**fx/**

Readiness scores (the five tests) are deferred until Compare (Phase 4). The schema gains an optional `readiness` block then, and nothing seeded now depends on it.

**Assembly rules added after spike S3 and Jason's review (28 Oct 2026):**
- **Every floor assembly states its ceiling/soffit finish layer** (role `ceiling`), even as an UnknownValue. Structural or sacrificial soffits (F-06, F-07, role `soffit`) don't count. This is enforced at build: zod rejects a floor with no `ceiling` layer. The gaps list shows it.
- **Timber floors** (family `bio_based` or `hybrid`) carry `toConfirm: "fire-rated ceiling needed for REI 60? (to confirm with the engineer)"` on that layer. Leaving it out would make the timber options look cheaper than beam-and-block.
- **`basedOn` is a label, not inheritance.** F-04 is `basedOn: "f-03b"` with `toConfirm: ["3A or 3B?"]` and lists its own layers.
- **Area layers with an unknown thickness** have a known quantity but an incomplete product spec. The sourcing step reports this as a price gap ("product spec incomplete: thickness unknown").
- **Unexplained residual depth** (stated depth minus known layers) is drawn as one hatched "indicative: unexplained depth" band in sections (Jason, 28 Oct 2026).

### 2.5 Derived model (computed, never stored)

1. **Element groups** from the layout: `floor:L1…Ln` (suspended floors), `wall:external`, `wall:party`, `wall:internal_structural`, `wall:partition`, `roof:main`, `frame:columns`, `frame:beams`. Each has a quantity (m² or m) and the formula used, shown on screen.
2. **Takeoff:** for each group → assigned assembly → layer: quantity per m² (from the `quantity` rule) × group area × (1 + wastage).
3. **Sourcing:** each layer resolves a product (sourcing override → preferred → first match on spec) and a route (product's supplier country → project destination, filtered by mode). If no regional product exists, the toggle is disabled with the reason ("no regional CLT supplier in library"), which is itself a finding.
4. **Landed rate** per purchase unit, in project currency, as additive components: `material`, `freight`, `insurance`, `duty`, `levy`, `clearing`, `haulage`. Each component is a Range plus the list of `MetricRef`s it depends on.
5. **BOQ line** `{key, section, itemRef, group, assembly, layer, description, unit, qty, rate, amount, components[], supplierDisplay, route, leadTime, carbon, basis, grade (weakest input), validated, gaps[]}` plus one installation line per assembly per group. Layout follows the QS/CAHF convention: elemental bill sections, item reference, description, unit, quantity, rate, amount. The exact CAHF section list and wording are a Phase 3 research task (grounded-citations, cited), not assumed here.
6. **Totals:** central amount prominently, low–high beside it; per m² GFA; per dwelling unit; carbon (kgCO2e, per m², beside cost); import share = Σ central amounts on imported routes / total central; basis label (first-of-kind / repeat / mixed). Lines with gaps are excluded and the total says "excludes N lines with unknown quantities or prices". **Any floor whose ceiling layer is unknown or unpriced carries a visible "ceiling not included" warning on its total, and so does every building total that includes that floor** (Jason, 28 Oct 2026).

### 2.6 % validated and the call list

- A **component is validated** when every input it depends on meets the validation policy. The policy (Decision 2 → A) is one table in `src/domain/validation-policy.ts`: prices, freight, insurance, clearing, haulage and installation rates need `quote_or_QS` or stronger; duty and levy rates and FX need `published_spec` or stronger (cited regulation or central-bank rate). Quantities and dimensions are tracked separately, as the quantity-basis grade on each line, and don't count towards cost % validated.
- **% validated** = Σ central(validated components) / Σ central(all priced components).
- **Biggest unvalidated numbers:** for each unvalidated `MetricRef`, the cost it gates = Σ central of the components it feeds. Sort descending, then by range width. Display: "Freight EU → Mombasa (USD/m3), placeholder, gates 18% of cost". This is the team's call list.
- Watermark shows while % validated < 80.

### 2.7 Checks

```ts
interface CheckAdapter {
  id: string; title: string; appliesTo: Element[];
  method: 'data_comparison' | 'calculation';
  validationStatus: Grade;              // a validated calculator declares its own grade later
  run(ctx: ProjectModel): CheckResult[];
}
type CheckResult = { checkId, groupId, assemblyId,
  status: 'meets' | 'straddles' | 'misses' | 'not_assessed',
  label: 'Data check', explanation: string, methodGrade: Grade, inputs: MetricRef[] };
```
v0.1 adapters, all `data_comparison`:

| Check | Rule |
|---|---|
| Acoustic | airborne is higher-better (meets if `low ≥ target`, misses if `high < target`); impact is lower-better. Unknown gives not_assessed |
| Fire | fireResistance minutes vs target, same rule |
| Depth/headroom | depth (lower-better) vs `maxFloorDepthMm` |
| Span | project span = the largest grid bay. ≤ assessed span gives meets; beyond it gives not_assessed, never misses ("not assessed beyond 3 m") |
| Budget | BOQ cost/m² range vs `budgetPerM2` |

`methodGrade` is the weakest grade of the inputs. Nothing says "OK".

```ts
// scripts/data-files.ts
import { readdirSync, readFileSync } from 'node:fs';
import { join, relative, sep } from 'node:path';

export type DataFile = { path: string; json: unknown };

export function readDataFiles(root: string): DataFile[] {
  return readdirSync(root, { recursive: true, withFileTypes: true })
    .filter((e) => e.isFile() && e.name.endsWith('.json'))
    .map((e) => {
      const full = join(e.parentPath, e.name);
      const path = relative(root, full).split(sep).join('/');
      try {
        return { path, json: JSON.parse(readFileSync(full, 'utf8')) as unknown };
      } catch (err) {
        throw new Error(`${path}: invalid JSON (${(err as Error).message})`);
      }
    })
    .sort((a, b) => (a.path < b.path ? -1 : a.path > b.path ? 1 : 0)); // code-point order, locale-independent
}
```

```ts
// spikes/s3-takeoff/range.ts
/** Bounds by interval arithmetic; central by applying the same operation to the centrals. */
export type Range = { low: number; central: number; high: number };

const EPS = 1e-9;
export const r = (low: number, high = low, central = (low + high) / 2): Range => {
  if (!(low <= central + EPS && central <= high + EPS)) throw new Error(`need low ≤ central ≤ high: ${low}, ${central}, ${high}`);
  return { low, central, high };
};
export const add = (a: Range, b: Range) => r(a.low + b.low, a.high + b.high, a.central + b.central);
export const mul = (a: Range, b: Range) => {
  const p = [a.low * b.low, a.low * b.high, a.high * b.low, a.high * b.high];
  return r(Math.min(...p), Math.max(...p), a.central * b.central);
};
export const div = (a: Range, b: Range) => {
  if (b.low <= 0 && b.high >= 0) throw new Error('divide by a range spanning zero');
  return mul(a, r(1 / b.high, 1 / b.low, 1 / b.central));
};
export const scale = (a: Range, k: number) => mul(a, r(k));
```

```ts
// spikes/s3-takeoff/takeoff.ts
import { add, div, mul, r, scale, type Range } from './range';
import { isUnknown, type Assembly, type Dim, type Layer, type MV, type Template } from './model';

const toRange = (m: MV): Range => r(m.low, m.high, m.central);

const val = (d: Dim, gaps: string[], label: string): Range | null => {
  if (isUnknown(d)) { gaps.push(...d.toConfirm.map((t) => `${label}: ${t}`)); return null; }
  return toRange(d);
};

export function qtyPerM2(layer: Layer): { perM2: Range | null; gaps: string[] } {
  const gaps: string[] = [];
  const { quantity: q, purchaseUnit: u, label } = layer;
  const bad = () => new Error(`${layer.id}: ${q.kind} cannot be bought per ${u}`);
  switch (q.kind) {
    case 'volume': {
      if (u !== 'm3') throw bad();
      const t = val(layer.thickness, gaps, label);
      return { perM2: t && scale(t, 1 / 1000), gaps };
    }
    case 'area':
      if (u !== 'm2') throw bad();
      return { perM2: r(1), gaps };
    case 'members': {
      if (u === 'm') {
        const s = val(q.spacing, gaps, label);
        return { perM2: s && div(r(1000), s), gaps };
      }
      if (u !== 'm3') throw bad();
      const w = val(q.width, gaps, label), d = val(layer.thickness, gaps, label), s = val(q.spacing, gaps, label);
      return { perM2: w && d && s ? div(scale(mul(w, d), 1 / 1000), s) : null, gaps };
    }
    case 'rate':
      return { perM2: val(q.rate, gaps, label), gaps };
  }
}

export function elementAreas(t: Template) {
  const lx = t.gridXM.reduce((a, b) => a + b, 0);
  const ly = t.gridYM.reduce((a, b) => a + b, 0);
  const plate = lx * ly - t.voidsM2PerStorey;
  return {
    floorPlateM2: plate,
    suspendedFloorM2: plate * (t.storeys - 1),
    roofM2: lx * ly,
    externalWallM2: 2 * (lx + ly) * t.storeyHeightM * t.storeys,
  };
}

export type LayerQty = { layerId: string; label: string; unit: string; perM2: Range | null; total: Range | null; gaps: string[] };

export function takeoff(a: Assembly, areaM2: number): LayerQty[] {
  return a.layers.map((layer) => {
    const { perM2, gaps } = qtyPerM2(layer);
    return { layerId: layer.id, label: layer.label, unit: layer.purchaseUnit, perM2, total: perM2 && scale(perM2, areaM2), gaps };
  });
}

export function depthBudget(a: Assembly) {
  const knownMm = a.layers.flatMap((l) => (isUnknown(l.thickness) ? [] : [toRange(l.thickness)])).reduce(add, r(0));
  const unknownLayers = a.layers.filter((l) => isUnknown(l.thickness)).map((l) => l.label);
  // Not clamped: a negative residual means the stated depth is smaller than the known layers (an inconsistency to report).
  let residualMm: Range | null = null;
  if (!isUnknown(a.depth)) {
    const d = toRange(a.depth);
    residualMm = r(d.low - knownMm.high, d.high - knownMm.low, d.central - knownMm.central);
  }
  return { knownMm, unknownLayers, residualMm, inconsistent: residualMm !== null && residualMm.high < 0 };
}
```

```ts
// spikes/s1-plan-editor/snap.ts
export type Pt = { x: number; y: number };
export type Grid = { x: number[]; y: number[] }; // cumulative positions in metres

export const positions = (spacings: number[]) =>
  spacings.reduce<number[]>((acc, s) => [...acc, acc[acc.length - 1]! + s], [0]);

const EPS = 1e-9;
const roundTo = (v: number, step: number) => Number((Math.round(v / step) * step).toFixed(3));
const nearest = (v: number, lines: number[]) =>
  lines.reduce((best, l) => (Math.abs(l - v) < Math.abs(best - v) ? l : best), lines[0]!);

/** Snap to a grid line when within tol on that axis, otherwise to the sub-grid; clamp to the grid extent. */
export function snap(p: Pt, grid: Grid, sub = 0.5, tol = 0.3): Pt {
  const axis = (v: number, lines: number[]) => {
    const n = nearest(v, lines);
    const s = Math.abs(n - v) <= tol + EPS ? n : roundTo(v, sub);
    return Math.min(Math.max(s, lines[0]!), lines[lines.length - 1]!);
  };
  return { x: axis(p.x, grid.x), y: axis(p.y, grid.y) };
}
```

```ts
// spikes/s1-plan-editor/walls.ts
export type WallType = 'external' | 'party' | 'internal_structural' | 'partition';
export type Wall = { id: string; x1: number; y1: number; x2: number; y2: number; type: WallType };

export const length = (w: Wall) => Math.hypot(w.x2 - w.x1, w.y2 - w.y1);
const key = (w: Wall) => [`${w.x1},${w.y1}`, `${w.x2},${w.y2}`].sort().join('|');

export function addWall(walls: Wall[], w: Wall): Wall[] {
  if (length(w) < 0.01) return walls;
  if (walls.some((x) => key(x) === key(w))) return walls;
  return [...walls, w];
}

export function totals(walls: Wall[]) {
  const lengthByType: Partial<Record<WallType, number>> = {};
  for (const w of walls) lengthByType[w.type] = (lengthByType[w.type] ?? 0) + length(w);
  return { count: walls.length, lengthByType };
}
```

```ts
// spikes/s2-massing/geometry.ts
export type Seg = { x1: number; y1: number; x2: number; y2: number };

/** Box transform for a unit cube: local +X runs along the wall. Three's +rotY turns +X toward −Z, hence the minus. */
export function wallToBox(w: Seg, storey: number, heightM: number, thicknessM: number) {
  const dx = w.x2 - w.x1, dz = w.y2 - w.y1;
  return {
    position: [(w.x1 + w.x2) / 2, storey * heightM + heightM / 2, (w.y1 + w.y2) / 2] as [number, number, number],
    rotationY: -Math.atan2(dz, dx),
    scale: [Math.hypot(dx, dz), heightM, thicknessM] as [number, number, number],
  };
}
```
