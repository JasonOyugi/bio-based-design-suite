# BASE parity checklist (v0.1)

v0.1 is a complete design version with the breadth of BASE's CBFT Design Suite. We match its workflow only, never its branding, wording, visuals or code. The checklist is part of the Phase 5 acceptance criteria (v0.1 plan §8). Each item is ticked after the screen that delivers it is dogfooded, with the commit that delivered it.
